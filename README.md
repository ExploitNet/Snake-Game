# 🐍 SNAKE — Neon Arcade

یک بازی کلاسیک **مار (Snake)** با ظاهری نئونی و حال‌وهوای آرکید، ساخته‌شده با **React 18 + TypeScript + Vite + Tailwind CSS v4** و رندر کاملاً روی **Canvas**. همه‌ی گرافیک‌ها و صداها به‌صورت procedural تولید شده‌اند — هیچ فایل تصویری یا صوتی خارجی در پروژه وجود ندارد.

## ✨ امکانات

### گیم‌پلی
- صفحه‌ی بازی **۲۱×۲۱** با حرکت نرم و بینابینی (Interpolated) — مار بین خانه‌ها سُر می‌خورد و در حالت Chill هنگام عبور از لبه‌ها به‌شکل پیوسته از سمت مقابل وارد می‌شود.
- **سه سطح سختی** با سرعت، شتاب و امتیاز متفاوت:

  | سطح | توضیح | سرعت اولیه | حداقل فاصله‌ی تیک | ضربدر امتیاز | برخورد با دیوار |
  |---|---|---|---|---|---|
  | 🟢 CHILL | آرام؛ دیوارها حلقه می‌شوند | 150ms | 96ms | ×1 | عبور از لبه |
  | 🟡 CLASSIC | قوانین آرکید کلاسیک | 112ms | 62ms | ×2 | مرگ |
  | 🔴 INSANE | سرعت سرسام‌آور؛ مخصوص حرفه‌ای‌ها | 82ms | 44ms | ×3 | مرگ |

- **سیب‌های پالس‌دار** و **ستاره‌ی طلایی پاداش** هر ۵ سیب (۵۰ امتیاز) با حلقه‌ی شمارش معکوس زنده.
- با هر سیب سرعت کمی بیشتر می‌شود (رشد تصاعدی با سقف امن).
- شرایط برد: پر کردن کامل صفحه → پیام «PERFECT!»؛ محافظت در برابر چرخش ۱۸۰ درجه و صف ورودی سه‌فرمانه برای چرخش‌های سریع و دقیق.

### کنترل‌ها

| ورودی | عملکرد |
|---|---|
| ⌨️ `↑ ↓ ← →` یا `W A S D` | هدایت مار |
| `Space` | توقف / ادامه + شروع از منو |
| `Enter` | شروع بازی / شروع دوباره |
| `R` | شروع دوباره |
| `M` | قطع/وصل صدا |
| `1 / 2 / 3` | انتخاب سطح سختی |
| 📱 کشیدن انگشت روی صفحه‌ی بازی (Swipe) | هدایت مار |
| 📱 D-Pad لمسی (نمایش خودکار در موبایل) | هدایت + دکمه‌ی مرکزی برای Pause |

- با تعویض تب یا از دست رفتن فوکوس، بازی **به‌صورت خودکار Pause** می‌شود.

### امتیاز و رکورد
- نمایش زنده‌ی امتیاز، **رکورد (Hi-Score) مجزا برای هر سطح سختی** و ذخیره در `localStorage`.
- نشان «NEW BEST» هنگام شکستن رکورد + بروزرسانی زنده‌ی Hi-Score در هدر.

### جلوه‌ها و حس بازی (Juice)
- ذرات انفجاری هنگام خوردن و مردن، اعداد شناور امتیاز، لرزش صفحه، درخشش سر مار، چشمک‌زدن چشم‌ها و بیرون‌زدن زبان.
- شمارش معکوس **3‑2‑1‑GO** قبل از شروع.
- صداهای سنتز‌شده با **WebAudio API** (بلپ خوردن، آرپژ پاداش، سقوط هنگام مرگ و…) با قابلیت Mute ماندگار.
- قاب CRT با اسکن‌لاین و وینیت، پس‌زمینه‌ی لایه‌لایه با شبکه‌ی پیکسلی متحرک و ذرات شناور.
- تایپوگرافی آرکید: فونت نمایشی **Press Start 2P** + فونت خوانا **Chakra Petch**.

## 🛠 تکنولوژی‌ها

- **React 18** — رابط کاربری، HUD و صفحه‌های منو/توقف/باخت
- **TypeScript** — تایپ‌های سراسری بازی (وضعیت‌ها، جهت‌ها، سختی‌ها)
- **Canvas 2D** — رندر ۶۰ فریم با `requestAnimationFrame` و جداسازی تیک‌های منطقی از رندر
- **WebAudio API** — سینت‌سایزر کوچک داخلی برای افکت‌های صوتی
- **Tailwind CSS v4** — توکن‌های رنگی سفارشی، انیمیشن‌ها و کلاس‌های آرکید
- **Vite 6** — بیلد و توسعه

## 🌍 استقرار روی GitHub Pages (لینک اختصاصی)

این پروژه ابزار بیلدش **Vite** است (نه webpack)، بنابراین به‌جای فایل webpack از یک **GitHub Actions Workflow** استفاده شده که با هر `push` به شاخه‌ی `main`، پروژه را به‌صورت خودکار بیلد و روی **GitHub Pages** منتشر می‌کند.

فایل Workflow: [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)

### مراحل (فقط یک‌بار)

1. **ساخت مخزن در GitHub** — یک Repository جدید بسازید (مثلاً `snake-neon-arcade`).

2. **آپلود کد:**

   ```bash
   git init
   git add .
   git commit -m "🐍 Snake — Neon Arcade"
   git branch -M main
   git remote add origin https://github.com/<نام-کاربری>/snake-neon-arcade.git
   git push -u origin main
   ```

3. **فعال‌سازی GitHub Pages** — در تنظیمات مخزن:
   `Settings → Pages → Build and deployment → Source` را روی **GitHub Actions** قرار دهید.

4. **تمام!** با هر push، Workflow به‌صورت خودکار اجرا می‌شود و چند ثانیه بعد بازی روی لینک اختصاصی شما در دسترس است:

   ```
   https://<نام-کاربری>.github.io/snake-neon-arcade/
   ```

   لینک دقیق هر بار در تب **Actions** (و سپس environment با نام `github-pages`) نمایش داده می‌شود.

### نکات

- بیلد با `--base=./` انجام می‌شود تا مسیر فایل‌ها نسبی باشد و بازی زیر دامنه‌ی `github.io/<repo>/` بدون هیچ تنظیم اضافی درست کار کند.
- Workflow فقط روی شاخه‌ی `main` اجرا می‌شود؛ برای تست می‌توانید آن را از تب Actions به‌صورت دستی (`Run workflow`) هم اجرا کنید.
- فایل‌های `node_modules` و `dist` توسط [`.gitignore`](.gitignore) از مخزن کنار گذاشته شده‌اند.

## 🧠 نکات پیاده‌سازی

- **معماری حلقه‌ی بازی:** منطق روی تیک‌های زمانی ثابت اجرا می‌شود و رندر با درون‌یابی بین دو تیک انجام می‌گیرد؛ نتیجه حرکت نرم و مستقل از نرخ فریم است.
- **ماشین حالت:** `menu → countdown → playing ⇄ paused → dying → gameover → menu` با تایمرهای مرگ و شمارش معکوس.
- **بدون asset خارجی:** سیب، ستاره، مار، قاب و آیکن‌ها همه با APIهای Canvas و SVG درون‌خطی کشیده شده‌اند؛ صداها هم با نوسان‌سازهای WebAudio ساخته می‌شوند.
- **سازگاری موبایل:** اندازه‌ی صفحه با `min()` و `dvh` واکنش‌گراست؛ دی‌پد فقط در دستگاه‌های لمسی نمایش داده می‌شود و از scroll ناخواسته هنگام بازی جلوگیری شده است.
- **دسترس‌پذیری:** دکمه‌ها `aria-label` دارند، فوکوس کیبورد مشخص است و رنگ‌های متن/پس‌زمینه کنتراست بالایی دارند.
